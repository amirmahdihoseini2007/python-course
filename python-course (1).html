پیش‌نیاز و درک برنامه‌نویسی

قبل از نوشتن حتی یک خط کد، باید بفهمی کامپیوتر اصلاً چطور «فکر می‌کند» و برنامه‌نویسی یعنی چه. این فصل پایه‌ی ذهنی لازم را می‌سازد.

کامپیوتر چطور کار می‌کند؟

کامپیوتر در اصل ماشینی است که فقط دو حالت می‌فهمد: روشن (۱) و خاموش (۰). هر چیزی که روی صفحه می‌بینی — متن، عکس، بازی — در پایین‌ترین لایه به رشته‌ای از صفر و یک (باینری) تبدیل شده است. پردازنده (CPU) این صفر و یک‌ها را به‌عنوان دستورالعمل می‌خواند و اجرا می‌کند.

نوشتن مستقیم صفر و یک برای انسان غیرممکن است، پس زبان‌های برنامه‌نویسی به‌وجود آمدند: زبانی نزدیک به زبان انسانی که بعداً توسط یک «مترجم» به زبان ماشین تبدیل می‌شود.

برنامه‌نویسی یعنی چه؟

برنامه‌نویسی یعنی نوشتن مجموعه‌ای از دستورالعمل‌های دقیق و مرحله‌به‌مرحله برای حل یک مسئله. مهم‌ترین مهارت یک برنامه‌نویس، توانایی «تجزیه‌ی مسئله» است: گرفتن یک مسئله‌ی بزرگ و شکستن آن به قدم‌های کوچک و قابل‌اجرا — که به آن الگوریتم می‌گویند.

مثال ساده‌ی الگوریتم: «درست کردن چای» = آب را بریز در کتری، کتری را روشن کن، صبر کن تا بجوشد، چای‌کیسه را در لیوان بگذار، آب جوش را روی آن بریز، ۳ دقیقه صبر کن. همین ساختار قدم‌به‌قدم، دقیقاً همان چیزی است که در کد می‌نویسیم.

چرا پایتون؟

  • خوانایی بالا — سینتکس پایتون شبیه جملات انگلیسی ساده است.
  • همه‌کاره — از توسعه وب و علم داده تا هوش مصنوعی و اسکریپت‌نویسی خودکارسازی.
  • جامعه‌ی بزرگ — کتابخانه‌ها و مستندات فراوان برای هر مسئله‌ای.
  • زبان تفسیری (Interpreted) — کد را خط‌به‌خط اجرا می‌کند، بدون نیاز به کامپایل جداگانه.

کد منبع، مفسر و کامپایلر

Compiled Language

کل کد یک‌جا به زبان ماشین ترجمه و به یک فایل اجرایی تبدیل می‌شود (مثل C++‎). سریع‌تر اجرا می‌شود اما مرحله‌ی کامپایل جدا دارد.

Interpreted Language

کد خط‌به‌خط توسط مفسر (interpreter) خوانده و اجرا می‌شود؛ پایتون از همین دسته است. توسعه سریع‌تر، اما اجرا کمی کندتر از زبان‌های کامپایل‌شده.

متغیرها (Variables)

متغیر یک «نام‌گذاری» برای یک مقدار در حافظه است. در پایتون نیازی به تعریف نوع داده نداری — پایتون خودش نوع را از روی مقدار تشخیص می‌دهد (Dynamic Typing).

variables.py
name = "سارا"       # رشته (str)
age = 28              # عدد صحیح (int)
height = 1.68         # عدد اعشاری (float)
is_student = False     # بولین (bool)

print(name, age, height, is_student)
print(type(age))    # نوع داده رو نشون میده
OUTPUTسارا 28 1.68 False <class 'int'>
این کد چیکار می‌کنه؟
=علامت مساوی در برنامه‌نویسی به‌معنی «برابری ریاضی» نیست، بلکه یعنی انتساب (assignment): مقدار سمت راست را داخل متغیر سمت چپ می‌ریزد. یعنی name = "سارا" یعنی «مقدار سارا را در متغیری به نام name ذخیره کن».
# ...هر چیزی بعد از علامت # یک کامنت (comment) است؛ پایتون آن را نادیده می‌گیرد. کامنت فقط برای توضیح دادن به خودت یا بقیه است.
type()تابعی که نوع داده‌ی یک مقدار را برمی‌گرداند؛ مثلاً می‌فهمی متغیری عدد صحیح (int) است یا رشته (str).
,داخل print() می‌توانی چند مقدار را با کاما جدا کنی؛ پایتون آن‌ها را با یک فاصله از هم چاپ می‌کند.
قانون نام‌گذاری متغیر: فقط حروف، عدد و آندرلاین (_)، نباید با عدد شروع شود، و به بزرگ/کوچک بودن حروف حساس است (age با Age فرق دارد). طبق قرارداد پایتون از snake_case استفاده می‌شود.

مدیریت شروط و حلقه‌ها

اینجاست که برنامه‌ها «هوشمند» می‌شوند: تصمیم‌گیری با شرط‌ها و تکرار کارها با حلقه‌ها.

دستور شرطی if / elif / else

grades.py
score = 78

if score >= 90:
    print("عالی")
elif score >= 70:
    print("خوب")
elif score >= 50:
    print("قابل قبول")
else:
    print("مردود")
OUTPUTخوب
این کد چیکار می‌کنه؟ (توضیح کامل هر کلمه)
ifیعنی «اگر». شرط جلوی آن را چک می‌کند؛ اگر درست (True) باشد، فقط بدنه‌ی زیر همان if اجرا می‌شود.
elifمخفف «else if»، یعنی «وگرنه اگر». وقتی شرط if بالا نادرست بود، این شرط جدید را چک می‌کند. می‌توانی هر تعداد elif که خواستی داشته باشی.
elseیعنی «در غیر این صورت». اگر هیچ‌کدام از شرط‌های بالا درست نبود، این بخش اجرا می‌شود. اختیاری است و همیشه آخرین بخش قرار می‌گیرد.
>=عملگر مقایسه‌ای «بزرگ‌تر یا مساوی». نتیجه‌ی هر مقایسه همیشه یک مقدار بولین (True یا False) است.
: و تورفتگیبعد از if، elif و else همیشه دو نقطه : می‌آید. خط بعدی باید یک فاصله (معمولاً ۴ فاصله) تورفته باشد تا پایتون بفهمد این خط، «داخل» همان شرط است.
در پایتون تورفتگی (indentation) جایگزین آکولاد {} در زبان‌های دیگر است. فراموش کردن تورفتگی صحیح باعث خطا می‌شود — این یکی از مهم‌ترین تفاوت‌های پایتون است.

حلقه‌ی while

حلقه‌ی while تا زمانی که شرط برقرار باشد، بدنه‌ی خودش را تکرار می‌کند.

countdown.py
count = 5
while count > 0:
    print(count)
    count -= 1   # معادل count = count - 1

print("پرتاب!")
OUTPUT5 4 3 2 1 پرتاب!
این کد چیکار می‌کنه؟
whileیعنی «تا وقتی که». تا زمانی که شرط جلوی آن True باشد، بدنه‌ی زیرش بارها و بارها تکرار می‌شود. وقتی شرط False شود، حلقه متوقف می‌شود.
count -= 1معادل کوتاه‌نویسیِ count = count - 1 است؛ یعنی یکی از مقدار count کم کن. مشابه آن +=، *= و /= هم وجود دارد.
⚠️ نکتهاگر شرط حلقه‌ی while هیچ‌وقت False نشود، برنامه برای همیشه اجرا می‌ماند؛ به آن حلقه‌ی بی‌نهایت (infinite loop) می‌گویند. همیشه مطمئن شو داخل حلقه چیزی هست که بالاخره شرط را نادرست می‌کند.

حلقه‌ی for

حلقه‌ی for برای پیمایش روی مجموعه‌ها (لیست، رشته، رنج و...) استفاده می‌شود.

for_loops.py
fruits = ["سیب", "موز", "پرتقال"]

# range(start, stop, step)
for i in range(1, 6):
    print(ff"مرحله {i}")
این کد چیکار می‌کنه؟
forیعنی «برای هر». برای پیمایش (رفتن روی تک‌تک اعضای) یک مجموعه مثل لیست، رشته یا رنج استفاده می‌شود.
inهمراه for می‌آید و یعنی «داخل». مشخص می‌کند از کدام مجموعه عضوها را یکی‌یکی برداریم.
range()دنباله‌ای از اعداد صحیح می‌سازد. range(1, 6) یعنی از ۱ شروع کن تا قبل از ۶ (یعنی ۱ تا ۵).

کنترل حلقه: break ،continue و else

loop_control.py
for num in range(1, 10):
    if num == 5:
        break       # کاملاً از حلقه خارج می‌شه
    if num % 2 == 0:
        continue    # این تکرار رو رد می‌کنه، ادامه میده
    print(num)
OUTPUT1 3
این کد چیکار می‌کنه؟
==عملگر «برابری» است، با علامت انتساب = اشتباه نگیر. == فقط مقایسه می‌کند و نتیجه‌اش True یا False است.
breakیعنی «بشکن». به‌محض رسیدن به این خط، پایتون فوراً از کل حلقه خارج می‌شود، حتی اگر هنوز اعضای دیگری باقی مانده باشد.
continueیعنی «ادامه بده». باقی‌ی کدهای این دور از حلقه را نادیده می‌گیرد و مستقیم می‌رود سراغ عضو بعدی — بدون این‌که از حلقه خارج شود.

لیست، تاپل، دیکشنری و مجموعه — چهار ساختار داده‌ای که تقریباً در هر برنامه‌ی پایتونی استفاده می‌شوند.

لیست (List) — قابل تغییر و مرتب

lists.py
numbers = [4, 8, 15, 16]

تاپل مثل لیست است اما بعد از ساخته شدن نمی‌توان آن را تغییر داد (Immutable). برای داده‌هایی که نباید تغییر کنند، مثل مختصات یا رنگ RGB، ایده‌آل است.

tuples.py

توابع و ماژول

توابع به تو اجازه می‌دهند کد را در قطعات قابل‌استفاده‌ی مجدد بسته‌بندی کنی. ماژول‌ها این قطعات را در فایل‌های جدا سازمان‌دهی می‌کنند.

تعریف و فراخوانی تابع

functions.py
def greet(name):
    return ff"سلام {name}!"

message = greet("مریم")
print(message)
این کد چیکار می‌کنه؟
defیعنی «تعریف کن». برای ساختن یک تابع جدید استفاده می‌شود. بعد از def، اسم تابع و داخل پرانتز پارامترهای ورودی‌اش می‌آید.
greetاسمی که خودمان برای تابع انتخاب کرده‌ایم؛ هر جا بعداً این اسم را با پرانتز صدا بزنیم، بدنه‌ی تابع اجرا می‌شود.
returnیعنی «برگردان». مقداری که جلوی آن نوشته شده را از تابع بیرون می‌فرستد تا بتوانیم در جای دیگری از آن استفاده کنیم. با اجرای return، تابع فوراً تمام می‌شود.
greet("مریم")این، فراخوانی (call) تابع است: نام تابع + پرانتز با مقدار ورودی. اینجا "مریم" به‌جای پارامتر name می‌نشیند.

پارامترهای پیش‌فرض، کلیدواژه‌ای و متغیر

params.py
def make_profile(name, age=18, *hobbies, **extra):
    print(ff"{name} - {age} ساله")
    print("سرگرمی‌ها:", hobbies)
    print("اطلاعات اضافه:", extra)

make_profile("نیما", 24, "شنا", "شطرنج", city="شیراز")
OUTPUTنیما - 24 ساله سرگرمی‌ها: ('شنا', 'شطرنج') اطلاعات اضافه: {'city': 'شیراز'}
  • پارامتر پیش‌فرض: age=18 — اگر مقدار داده نشود همین را می‌گیرد.
  • args* — تعداد نامشخصی آرگومان موقعیتی را به‌صورت تاپل می‌گیرد.
  • kwargs** — تعداد نامشخصی آرگومان کلیدواژه‌ای را به‌صورت دیکشنری می‌گیرد.

مدیریت خطا

هیچ برنامه‌ای بدون خطا نیست. یاد بگیر چطور خطاها را پیش‌بینی، مدیریت و حتی خودت خطای سفارشی بسازی.

try / except پایه

error_basic.py
try:
    number = int(input("یک عدد وارد کن: "))
    result = 10 / number
    print(result)
except ValueError:
    print("باید یک عدد وارد می‌کردی!")
except ZeroDivisionError:
    print("نمی‌شه بر صفر تقسیم کرد!")
این کد چیکار می‌کنه؟
tryیعنی «امتحان کن». کدی که ممکن است خطا بدهد را داخل این بلوک می‌گذاری تا اگر خطا رخ داد، برنامه به‌جای کرش‌کردن، کنترل‌شده ادامه پیدا کند.
exceptیعنی «به‌جز/مگر». اگر داخل try خطایی از نوع مشخص‌شده رخ دهد، کد داخل همین بلوک اجرا می‌شود به‌جای این‌که برنامه متوقف شود.
ValueErrorیک نوع خطای از پیش تعریف‌شده در پایتون؛ وقتی رخ می‌دهد که مقداری با نوع نامناسب داده شود، مثلاً تلاش برای تبدیل متن غیرعددی به عدد.
ZeroDivisionErrorنوع دیگری از خطا که وقتی عددی بر صفر تقسیم شود رخ می‌دهد.

else و finally

full_try.py
try:
    f = open("data.txt")
except FileNotFoundError:
    print("فایل پیدا نشد")
else:
    print("فایل با موفقیت باز شد")
    f.close()
finally:
    print("این خط همیشه اجرا می‌شه، چه خطا باشه چه نباشه")
  • else — فقط وقتی بلاک try بدون خطا تمام شد اجرا می‌شود.
  • finally — همیشه اجرا می‌شود؛ مناسب برای بستن فایل یا اتصال دیتابیس.

ساختارهای تابع‌گرا

برنامه‌نویسی تابعی (Functional Programming) در پایتون: توابع به‌عنوان مقدار، lambda، و ابزارهایی مثل map و filter.

توابع به‌عنوان شهروند درجه‌یک (First-Class Functions)

در پایتون، تابع را می‌توان مثل یک متغیر عادی به تابع دیگر پاس داد، در متغیر ذخیره کرد، یا از تابعی دیگر برگرداند.

first_class.py
def shout(text):
    return text.upper() + "!"

def apply_function(func, value):
    return func(value)

print(apply_function(shout, "hello"))  # HELLO!

توابع بی‌نام: lambda

lambda_demo.py
square = lambda x: x ** 2
print(square(6))   # 36

# کاربرد رایج: کلید مرتب‌سازی سفارشی
people = [("سارا", 25), ("رضا", 19), ("مینا", 31)]
people.sort(key=lambda person: person[1])
print(people)   # مرتب بر اساس سن
این کد چیکار می‌کنه؟
lambdaراهی کوتاه برای ساخت یک تابع «بی‌نام» در یک خط، بدون نیاز به def. فرمتش: lambda ورودی: خروجی. معمولاً برای توابع خیلی کوتاه و یک‌بارمصرف استفاده می‌شود.
sort(key=...)پارامتر key به sort می‌گوید بر چه اساسی مرتب کند؛ اینجا با lambda گفته‌ایم بر اساس عضو دومِ هر تاپل (سن) مرتب کن.

map ،filter و reduce

map_filter.py
from functools import reduce

numbers = [1, 2, 3, 4, 5]

doubled = list(map(lambda x: x * 2, numbers))
print(doubled)      # [2, 4, 6, 8, 10]

evens = list(filter(lambda x: x % 2 == 0, numbers))
print(evens)        # [2, 4]

total = reduce(lambda acc, x: acc + x, numbers)
print(total)        # 15
این کد چیکار می‌کنه؟
map()همان تابع را روی تک‌تک اعضای یک لیست اجرا می‌کند و یک نتیجه‌ی جدید برمی‌گرداند؛ اینجا هر عدد را دوبرابر می‌کند.
filter()فقط عضوهایی از لیست را نگه می‌دارد که تابع شرط برایشان True برگرداند؛ بقیه دور ریخته می‌شوند.
reduce()همه‌ی اعضای لیست را دو‌تا‌دوتا با هم ترکیب می‌کند تا به یک مقدار نهایی برسد؛ اینجا همه را جمع می‌زند.
list()نتیجه‌ی map و filter به‌طور پیش‌فرض به‌شکل قابل چاپ ساده نیست؛ با list() آن را به یک لیست معمولی تبدیل می‌کنیم.

تابع مولد (Generator) و yield

جنریتور به‌جای برگرداندن همه‌ی مقادیر یک‌جا، مقادیر را یکی‌یکی و «تنبل» (Lazy) تولید می‌کند — برای داده‌های حجیم بسیار بهینه است.

generator.py
def count_up_to(limit):
    n = 1
    while n <= limit:
        yield n
        n += 1

for number in count_up_to(5):
    print(number)
این کد چیکار می‌کنه؟
yieldشبیه return است، اما به‌جای تمام‌کردن تابع، فقط یک مقدار را «موقتاً» برمی‌گرداند و محل خودش را به خاطر می‌سپارد؛ دفعه‌ی بعد که تابع صدا زده شود، دقیقاً از همان‌جا ادامه می‌دهد.
تابع مولدهر تابعی که داخلش حداقل یک yield داشته باشد، به‌جای اجرای معمولی، یک «جنریتور» می‌سازد که مقادیر را یکی‌یکی و در لحظه تولید می‌کند، نه همه را یک‌جا در حافظه.

دکوریتور (Decorator)

دکوریتور تابعی است که تابع دیگری را می‌گیرد و رفتار آن را بدون تغییر کد اصلی‌اش، گسترش می‌دهد.

decorator.py
import time

def timer(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(ff"{func.__name__} در {time.time()-start:.4f} ثانیه اجرا شد")
        return result
    return wrapper

@timer
def slow_task():
    time.sleep(1)

slow_task()

شئ‌گرایی در پایتون

برنامه‌نویسی شئ‌گرا (OOP) روشی برای مدل‌سازی دنیای واقعی در کد است: کلاس‌ها، اشیاء، وراثت و چندریختی.

کلاس و شیء

class_basic.py
class Dog:
    def __init__(self, name, breed):
        self.name = name        # attribute (ویژگی)
        self.breed = breed

    def bark(self):              # method (متد)
        return ff"{self.name} گفت: واق واق!"

my_dog = Dog("رکس", "ژرمن شپرد")   # نمونه‌سازی (instantiation)
print(my_dog.bark())
OUTPUTرکس گفت: واق واق!
این کد چیکار می‌کنه؟
classیعنی «کلاس». یک قالب/نقشه برای ساخت اشیاء مشابه تعریف می‌کند؛ مثلاً کلاس Dog، نقشه‌ی همه‌ی سگ‌هاست، نه یک سگ خاص.
__init__متد «سازنده» (constructor). به‌محض ساخته‌شدن یک شیء جدید از کلاس، این متد خودکار اجرا می‌شود و مقدارهای اولیه را تنظیم می‌کند.
selfاشاره‌گر به «خودِ شیء». همیشه اولین پارامتر هر متد است و اجازه می‌دهد داخل کلاس به ویژگی‌های همان شیء (مثل self.name) دسترسی داشته باشیم.
Dog("رکس"...)این خط یک شیء (object) واقعی از روی کلاس Dog می‌سازد؛ به این کار نمونه‌سازی (instantiation) می‌گویند.
my_dog.bark()برای صدا زدن متد یک شیء، بعد از نام شیء یک نقطه می‌گذاریم و اسم متد را با پرانتز می‌آوریم.

وراثت (Inheritance)

inheritance.py
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "..."

class Cat(Animal):                # Cat از Animal ارث‌بری می‌کنه
    def speak(self):             # override کردن متد والد
        return ff"{self.name} می‌گه: میو!"

c = Cat("پیشی")
print(c.speak())
این کد چیکار می‌کنه؟
class Cat(Animal)پرانتز جلوی نام کلاس یعنی «کلاس والد» (parent). این یعنی Cat همه‌ی ویژگی‌ها و متدهای Animal را به ارث می‌برد و می‌تواند چیزهای بیشتری هم به آن‌ها اضافه یا آن‌ها را تغییر دهد.
overrideوقتی کلاس فرزند متدی با همان اسم متد والد تعریف می‌کند تا رفتار آن را جایگزین کند؛ اینجا Cat متد speak را دوباره‌نویسی کرده است.

Encapsulation و property

encapsulation.py
class BankAccount:
    def __init__(self, balance):
        self.__balance = balance   # __ یعنی private (محافظت‌شده)

    @property
    def balance(self):
        return self.__balance

    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount

acc = BankAccount(1000)
acc.deposit(500)
print(acc.balance)   # 1500 — دسترسی کنترل‌شده به موجودی

متدهای جادویی (Dunder Methods)

dunder.py
class Vector:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __add__(self, other):        # عملگر + رو تعریف می‌کنه
        return Vector(self.x + other.x, self.y + other.y)

    def __str__(self):             # چطور با print نمایش داده بشه
        return ff"Vector({self.x}, {self.y})"

v1, v2 = Vector(1, 2), Vector(3, 4)
print(v1 + v2)   # Vector(4, 6)

ایزوله‌سازی محیط توسعه

محیط مجازی (Virtual Environment) به هر پروژه اجازه می‌دهد کتابخانه‌های خودش را جدا از پروژه‌های دیگر داشته باشد — بدون تداخل نسخه.

چرا محیط مجازی لازم است؟

فرض کن پروژه‌ی A به نسخه‌ی ۱ یک کتابخانه نیاز دارد و پروژه‌ی B به نسخه‌ی ۲ همان کتابخانه. اگر همه چیز را روی سیستم نصب کنی، این دو با هم تداخل پیدا می‌کنند. محیط مجازی این مشکل را با ساختن یک نصب مجزای پایتون برای هر پروژه حل می‌کند.

ساخت و فعال‌سازی venv

terminal
# ساخت محیط مجازی به نام venv
python -m venv venv

# فعال‌سازی در ویندوز
venv\Scripts\activate

# فعال‌سازی در macOS / Linux
source venv/bin/activate

# حالا نصب پکیج فقط داخل این محیط انجام می‌شه
pip install pandas

# خروج از محیط مجازی
deactivate
وقتی محیط مجازی فعال است، نام آن معمولاً در ابتدای خط ترمینال، داخل پرانتز، نشان داده می‌شود؛ مثل (venv) user@machine:~$.

DRY: Don't Repeat Yourself

اگر یک منطق را بیش از یک‌بار کپی‌پیست می‌کنی، آن را در یک تابع جدا کن. تکرار کد یعنی هر باگ باید در چند جا فیکس شود.

Docstring و Type Hints

documented.py
def calculate_bmi(weight: float, height: float) -> float:
    """
    محاسبه‌ی شاخص توده بدنی (BMI)

    Args:
        weight: وزن به کیلوگرم
        height: قد به متر

    Returns:
        مقدار BMI به‌صورت عدد اعشاری
    """
    return weight / (height ** 2)
Type Hintها (مثل weight: float) اجباری نیستند اما به ابزارهایی مثل VSCode و mypy کمک می‌کنند خطاهای احتمالی را زودتر پیدا کنند.

PEP 8: استاندارد رسمی سبک نوشتن

  • استفاده از ۴ فاصله برای تورفتگی، نه تب.
  • نام متغیر و تابع: snake_case
  • نام کلاس: PascalCase
  • نام ثابت‌ها: ALL_CAPS
  • حداکثر طول خط: معمولاً ۷۹ تا ۹۹ کاراکتر
  • دو خط خالی بین تعریف کلاس‌ها و توابع سطح بالا
ابزار black یا ruff را نصب کن تا کدت به‌طور خودکار طبق PEP 8 فرمت شود — دیگر نیازی نیست نگران فاصله‌گذاری باشی.

مدیریت حافظه و Garbage Collection

پایتون حافظه را به‌صورت خودکار مدیریت می‌کند. وقتی هیچ متغیری به یک شیء اشاره نکند، جمع‌کننده‌ی زباله (Garbage Collector) آن را از حافظه پاک می‌کند — نیازی به آزادسازی دستی حافظه مثل C نیست.

Mutable در برابر Immutable

mutability.py
a = [1, 2, 3]
b = a          # b به همون شیء اشاره می‌کنه، نه کپی جدید
b.append(4)
print(a)      # [1, 2, 3, 4] ← a هم تغییر کرد!

x = 5
y = x
y += 1
print(x)      # 5 ← اعداد immutable هستن، تغییر نمی‌کنن
این یکی از رایج‌ترین منابع باگ برای تازه‌کارهاست: لیست، دیکشنری و شیء از کلاس‌های سفارشی Mutable هستند و با کپی ساده اشتراک حافظه دارند. برای کپی واقعی از list(a) یا ماژول copy استفاده کن.
